# Jam Master

אפליקציית תרגול לנגנים בהרכב: מנגנים את השיר באוזניות, מקליטים את עצמך מעליו, ומקבלים דוח על תווים לא נכונים ועל כניסות מוקדמות/מאוחרות, לפי התווים.

- **האתר:** https://barakgeller-maker.github.io/-Jam-Master-/
- עובד בדפדפן של הטלפון (Chrome / Safari). אפשר "להוסיף למסך הבית" ולקבל אייקון כמו אפליקציה.
- הכל רץ על הטלפון: הקלטות ושירים נשמרים רק במכשיר.
- ההקלטות של ההרכב לא נמצאות במאגר הזה. בשירי הדוגמה בוחרים את קובץ השיר פעם אחת מהטלפון.

## מבנה
- `index.html`, `style.css` – המסכים
- `app.js` – ניווט, נגינה, הקלטה, ג׳אם חדש, סנכרון בהקשה
- `analysis.js` – זיהוי גובה צליל (YIN) והשוואה לתווים
- `omr.js` – קריאת תווים מקובצי PDF שיצאו מתוכנת תווים (MuseScore, Sibelius וכו'), בלי זיהוי תמונה
- `music.js` – כלים (טרנספוזיציה), קריאת MusicXML, מפת פעמות
- `demos/` – התווים של שירי הדוגמה (תומללו מה-PDF) ומפת הסנכרון שלהם
